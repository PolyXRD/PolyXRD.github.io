项目简介

只做一件事：层状 NCM 的精修

PolyXRD NCM 是 PolyXRD 家族中专攻三元锂电正极材料的成员。它不做通用的谱图处理， 也不追求覆盖所有材料体系，而是把两个问题回答清楚：这张谱是不是 NCM， 以及这个 NCM 的晶体学参数是多少。

判定不通过时，程序会停下来并说明理由，而不是把非 NCM 的谱硬套进精修。 判定通过后，晶胞参数、晶粒尺寸、Li 占位与拟合优度一次给出，观测谱、计算谱与差值曲线同屏对照。

工作流

三步，从一张谱图到一份结果

不需要记参数、不需要写脚本。打开谱图，剩下的判断与计算由程序按固定顺序完成。

导入谱图

打开仪器导出的谱图文件，画布立即显示原始曲线；结构类型判定同时在后台完成。

打开即读谱 · 自动触发判定

确认结构

内置 811 / 622 / 523 / 111 与前驱体标准结构，开箱即选；也可以导入自己的晶体结构文件。

结构不匹配 · 不放行精修

全谱精修

以所选结构为起点联合精修，观测谱、计算谱与差值曲线实时对照；完成后结果卡一次填满。

晶胞 · 峰形 · 择优取向 · 晶粒 · 占位
功能特性

为一份能交出去的结果而设计

从读谱到导出，每一步都有明确的输入、口径与可核查的输出。

谱图预处理

平滑、扣背景、去 Kα2、单峰拟合与寻峰随手可用；所有处理只改变显示谱，进入精修的始终是原始谱。

显示谱与精修谱分离

物相判定门

峰位序列、双峰可分辨与特征强度比三重校验。不是层状三元正极，就不进入精修，并给出具体原因。

判定不通过即停止

全谱精修

晶胞、峰形、择优取向、晶粒尺寸与 Li 占位在同一条流程里联合求解，避免单峰法各自为政。

观测 / 计算 / 差值同屏

结果卡

结果与口径

数字要经得起复核

精修完成时，右侧结果卡按六个分区给出全部结论；导出报告沿用同一套口径。

  • 晶体学结构、空间群、晶系、点群、劳厄群与布拉维格子
  • 晶胞参数a / b / c、α / β / γ、晶胞体积与 c/a
  • 组成与占位Li 占位与层间 O 的位置参数
  • 微结构晶粒尺寸与微观应变，超出检出上限时如实标注
  • 峰形参数零位偏移、峰宽、不对称、温度因子与择优取向
  • 拟合优度Rwp / Rp / Rexp / RB / GOF，一眼判断结果可用性

先判定，再精修

结构对不上就停下来并说明原因，不用错误的模型硬算出一组好看的数字。

原始谱进精修

平滑与扣背景只用于看图与寻峰，不改变送入精修的谱，避免处理步骤污染残差。

不写假精度

「未测定」与「测得 0」严格区分；检出上限之外的量如实标注，不显示 0.000。
