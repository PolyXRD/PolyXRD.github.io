项目简介

只做一件事：石墨化度与微晶尺寸

Graphite 是 PolyXRD 家族中专攻石墨材料 XRD 结构参数的成员。它不做通用谱图处理， 而是把「寻峰 → 内标校正 → 宽化扣除 → 计算 → 报告」串成一条可执行、可追溯的链路： 自动标定 C(002) 与 Si(111)，用 Si 标样得到仪器宽化，最终给出 g、Lc、La。

石墨化度以层间距 d002 表达，并明确区分层堆叠方向（Lc）与层内晶畴尺寸（La）； 没有 Si 内标的样品在批处理中仍会列出，但明确标注未做零位校正——不把未校正的数据混进合规结论。

功能流程

按操作流程排页签，一步不跳

谱图与寻峰 → Si 标样 / 仪器宽化 → 计算 → 结果与报告；批处理可独立运行，口径与单谱计算一致。

①自动寻峰与相标记

读取两列文本谱后自动寻峰，每个峰做拟合，并在谱图上挂出相标记与四位小数峰位。

  • 格式直读：.txt .xy .dat .csv .asc .prn，自动跳过注释与表头
  • 自动标记：C(002) 在 25.0–27.0° 内就近锁定，Si(111) 在 28.4°±0.6° 内锁定，并填入计算页
  • 峰表：峰位、d、FWHM、峰高、相对强度、η、R² 与 Centroid 2θ 一屏可查
  • 标注避让：峰顶标签自动错层，不压曲线、不越边框；可一键关掉得到干净谱图

弱峰质心与定点拟合

石墨 (110) 强度常低于 (002) 的 5%，容易被寻峰阈值滤掉；质心则给出另一种峰位口径。

  • Centroid：扣背底后的强度加权平均角，与 MDI Jade 峰表 Centroid 同一定义
  • 双口径：拟合峰顶 / 质心切换即时重填；两峰靠近时质心标签自动错层
  • 定点拟合：输入 2θ 即在该位置定向拟合，弱峰也能得到 FWHM
  • 删除误识别峰：仅从峰表与谱图移除，不改原始数据；重新寻峰即可恢复

②Si 标样全角度扫描

读入纯 Si（或 LaB₆）标样谱，按理论峰位识别各条反射并逐峰拟合 FWHM。

  • 峰识别：111 / 220 / 311 / 400 / 331 / 422 / 511 / 440 / 531 …
  • 制样一致：标样与样品同狭缝、同扫描参数，几何误差才能点对点扣除
  • 全角度：建议扫 20–120°，低角 (111) 与高角 (531)/(422) 同时参与拟合
  • 一次拟合，两处使用：结果自动用于 C(002) 与 (110) 两处的仪器宽化

宽化自动反算仪器宽化

对逐峰 FWHM 做整体拟合，得到整台仪器的宽化曲线，而不是只用一个常数。

  • 输出：拟合参数、RMS 与参与拟合的点数，拟合质量一眼可判
  • 扣除模型：平方（高斯）或线性（洛伦兹），界面二选一
  • 一致性：同批样品必须用同一模型，并在报告中注明
  • 兜底：也可直接给定仪器 FWHM，适合已有仪器校准记录的实验室

③内标校正与计算

用 Si(111) 的实测与标准 2θ 求出零位偏差，同量加到 C(002) 与 La 峰，再完成三项结果计算。

  • 石墨化度 g：由校正后的 d002 直接换算，0–100% 一目了然
  • Lc / La：分别对应层堆叠方向与层内晶畴尺寸，La 优先用 (110)
  • 波长：Cu/Co/Mo/Fe/Cr 的 Kα1、Kα2 或 Kα 平均，也可自定义
  • 结果卡：g、Lc、La、d002 同屏给出，明细表逐项留痕

提示判据与报告导出

结果卡下方主动提示可疑结果；报告可一键导出，直接随测试报告归档。

  • 自动提示：g 越界、La 峰位偏离理论值、仪器宽化缺失、d002 与峰位不匹配
  • 明细表：Δ2θ、各峰仪器宽化、纯宽化逐项列出，便于复核
  • TXT 报告：含公式、K 值、宽化模型与提示
  • CSV：UTF-8 BOM，Excel 直接打开不乱码

批一个文件夹，一次算完

选一个文件夹，自动读取其中全部谱图，标定 C(002) 与 Si(111)，逐谱计算石墨化度 g 并在表格展示。

  • 批量标定：C(002) 25.0–27.0°、Si(111) 28.4°±0.6°，与单谱页同一实现
  • 无 Si 也列出：g 不做零位校正并明确标注；22–25° 无定形鼓包不作为 (002) 峰
  • 结果表：文件、C(002)、Si(111)、d002、g、Si 校正、状态/备注，共 7 列
  • 断点友好：已导出的结果 CSV 在下次扫描时自动跳过

CSV口径一致，可复核

批处理与单谱计算共用峰位口径（拟合峰顶 / 质心），导出结果可直接进 Excel 继续统计。

  • 异常样品在表中标红，并在备注列写明原因
  • 波长与最小相对强度可在批处理页独立设置
  • 导出 CSV 为 UTF-8 BOM，Excel 双击即开
  • 处理进度与成功数显示在批处理页底部状态栏
功能特性

为一张能交出去的报告而设计

每一个输入、每一项口径、每一处提示，都能在界面与报告里找到出处。

自动标定 C(002)

25.0–27.0° 覆盖高结晶石墨、半石墨化炭与乱层炭，并排除低温炭 22–25° 的无定形弥散鼓包，不会把鼓包当成 (002) 峰。

C(002) 25.0–27.0° · Si(111) 28.4°±0.6°

质心与峰顶双口径

拟合峰顶与 Centroid 同时标注（四个角度值互不遮挡），「质心→C(002)」「质心→Si(111)」一键填表，批处理亦可切换口径。

拟合峰顶 / 质心 · 一键切换

弱峰定点拟合

(110) 的强度常低于 (002) 的 5%，按输入 2θ 定向拟合，La 不再因寻峰阈值被漏掉；72–82° 的高角度也带来更高分辨率。

77.5° · 72–82° · La 优先路径

Si 内标零位校正

装样高度、表面离焦与透明效应会整体推移峰位；内标法点对点扣除，0.01° 的峰位偏差约对应 0.15 个百分点的 g 偏差。

Δ2θ 同量加到 C(002) 与 La

三语界面热切换

简体中文、English、日本語，运行中从菜单栏即时切换，选择记忆在本地；方法说明随语言显示对应内容。

zh_CN / en_US / ja_JP
