01 / 项目简介

只做一件事：把结构变成可信的谱

PolyXRD 家族成员
谱图合成 · 桌面端工具
为什么需要合成

真实的衍射谱从不“干净”。峰有宽度、背底会抬起、计数存在波动——只靠理论峰位的理想谱图，往往无法验证一条检索或分析方法是否真的有效。

SynthPattern 把这些仪器层面的因素一并纳入合成过程：峰位与相对强度由结构决定，峰形、背底与噪音由可调的仪器参数决定。

生成谱的目的不是“看起来像”，
而是“能被检索软件正确命中”。
A

物相检索验证

用已知物相的合成谱检验检索流程与参数设置，确认管线对已知答案是否可靠。

B

方法开发与标定

构造指定物相、指定比例、指定仪器条件的标准谱，作为方法比对的参照。

C

教学与演示

直观展示多相混合、峰形展宽、择优取向等因素如何改变一张衍射谱。

D

混合谱构造

把手头的实测谱按比例叠加，快速得到组合谱用于对比与说明。

02 / 合成方式

两条路径，同一份可信结果

从结构出发，或从已有的实测谱出发——两者的输出都会落在同一套坐标与格式约定上。

顶部标签页一键切换
结果实时显示在右侧
A
方式一

从晶体结构合成

选择一个或多个晶体结构文件，按质量分数混合，直接得到覆盖整个角度范围的一张完整谱图。峰位来自结构，相对强度来自结构因子。

  • 多相按质量分数自动混合
  • 覆盖任意起始 / 终止角与步长
  • 输出为整数计数强度
  • 可叠加真实的峰形、背底与噪音
INPUT · CIF → OUTPUT · PATTERN
B
方式二

叠加实测谱

把两条及以上的实测谱放到同一个角度网格上，为每一条设置独立的比例因子，按比例叠加成一条混合谱，并可直接设定目标峰值。

  • 支持任意条实测谱
  • 每条谱独立比例因子
  • 统一网格，叠加结果即用
  • 可设定叠加后的目标峰值
INPUT · MEASURED × N → OUTPUT · MIXED
03 / 仪器特征

不只是峰位，把仪器也一起模拟

峰形、背底、噪音与强度标度共同决定一张谱是否“像实测谱”。这四项都可以单独调节，也可以交给标样反算。

峰形

采用 pseudo-Voigt 峰形，峰宽与洛伦兹比例分别可调，兼顾仪器展宽与自然线宽。

背底

两参数线性背底，随角度缓慢抬升，模拟真实测量中的散射背景。

噪音

以峰值强度为基准的高斯噪音，强度可调；适当的噪音是检索能否命中的关键。

强度整数化

最终输出为整数计数，与仪器导出的数据口径一致，便于直接比对。

参数从哪里来？两种取值方式

a
推荐值 · 开箱即用

按常规实验室 Cu 源条件预设的一组参数，适合快速得到一张可直接用于检索验证的谱。

b
由实测标样反算

导入自己仪器实测的 Si / LaB6 谱，或直接使用内置标样，自动反算出峰形、洛伦兹比例、背底与噪音，并叠加到结构谱上——让合成谱更贴近本机仪器。

04 / 物理修正

需要更真实的谱时，再加一点物理

五项可选修正，默认全部关闭。每一项都会让谱图更接近真实测量，也会让结果偏离默认标定——按需开启。

默认关闭
按需逐项启用
01

Kα1 / Kα2 双线 默认关闭

两条分量各自满足 Bragg 关系，间隔随角度增大——高角度处的峰自然分裂为双线，强度比可调。

02

择优取向 逐相设置

按晶面为每个物相单独设置取向参数，模拟片状或柱状晶粒造成的相对强度变化；不设置即为无择优。

03

晶粒尺寸 纳米级

按 Scherrer 关系随角度展宽峰形，输入纳米级晶粒尺寸即可看到小晶粒带来的明显宽化。

04

微应变 百分比

叠加随角度增大的应变展宽，以百分比输入；与晶粒尺寸可同时启用，二者按各自机制合成。

05

有限厚度吸收 μ 与厚度

输入线吸收系数与样品厚度，压低高角度一侧的相对强度，模拟薄层或低吸收样品的测量效果。

ⓘ
提示：修正开启后，谱图将不再等同于默认标定谱。若用于第三方检索验证，请以修正后的谱重新确认命中结果。
05 / 导出格式

四种格式，覆盖常见下游软件

导出即所得：文本、定宽两列与带表头两列，覆盖检索、精修与绘图工具的导入习惯。

.txt

Profile Data Ascii

带测量条件头的 ASCII 全谱格式，字段与行宽遵循通行约定，可直接被多数检索软件识别。

.xy

定宽两列

角度与强度两列定宽输出，绘图与快速查看的通用选择。

.dat

定宽两列

与 .xy 相同的数据组织方式，适配偏好 .dat 后缀的软件与流程。

.csv

带表头两列

列名清晰，便于表格软件直接打开、筛选与二次处理。

一致性：无论使用哪条合成路径、开启哪些修正，导出都遵循同一套坐标与格式约定，便于互相比较。
