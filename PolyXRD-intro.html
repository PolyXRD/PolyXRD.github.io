功能总览

从读谱到出报告，每一步都有趁手的工具

围绕日常粉末衍射分析的真实流程设计，不把功能拆散在多个窗口里，也不需要来回倒数据。

谱图导入与预处理

直接读取常见仪器导出的衍射数据；平滑、背景扣除、Kα₂ 剥离与仪器校准一应俱全，让谱图在分析前就处于干净、可比的状态。

导入 · 平滑 · 扣背景 · 校准

峰检测与峰形拟合

自动寻峰并给出峰位、强度与半高宽，支持二阶导数寻峰与多种峰形拟合，弱峰、重叠峰同样有据可依。

寻峰 · 拟合 · 半高宽

多物相检索

基于 d–I 匹配与预筛评分，支持化学式、元素约束（必含 / 含 / 可能 / 排除）和交互式元素周期表；多相依次检索，每个候选都有明确的采纳 / 复核 / 否决结论。

d–I 匹配 · 元素约束 · 逐相判定

Rietveld / Le Bail 全谱精修

内置全谱精修能力，分阶段策略、失败回滚与结构化诊断；同步提供 Le Bail 晶胞精修，也可按需联动常用外部精修软件。

全谱拟合 · 分阶段 · 回滚

晶体结构与指标化

立方、四方、六方晶系自动指标化；CIF 浏览与 3D 晶胞渲染，让衍射峰、晶面与结构参数一一对应。

指标化 · CIF · 3D 晶胞

项目与报告

项目文件完整保存参数与谱图，随时回到当时的分析状态；一键导出 CSV / PNG / SVG / PDF，支持批量报告，结果可复现、可追溯。

项目归档 · 批量报告 · 多格式导出
工作流程

一条链路，从原始数据到最终结论

模块之间共享同一份谱图与参数，任何一步的修改都能立即反映到后续结果。

导入谱图

原生格式直读，自动识别角度轴与强度。

预处理

平滑、扣背景、剥离 Kα₂、仪器校准。

寻峰拟合

二阶导数寻峰，拟合峰位、强度、半高宽。

物相检索

元素与化学式约束收敛候选，多相依次确认。

全谱精修

Rietveld / Le Bail，分阶段策略与诊断。

报告导出

PDF / CSV / PNG / SVG，批量归档。

数据与格式

仪器输出的文件，打开就能分析

兼容常见衍射数据格式与晶体数据库，减少格式转换带来的额外工作。

谱图格式

支持主流仪器导出的原始谱图与通用文本格式；也可将谱图另存为通用格式，方便与其他软件交换。

.xrdml .raw .txt .csv .xy .dat

晶体数据库

内置开放晶体学数据库，安装即用；也可以挂载自有数据库。

  • 数据库切换后立即生效，无需重启软件
  • 支持多个数据库并行挂载与随时卸载
  • 检索结果直接进入物相候选列表
